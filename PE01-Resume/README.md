# PE01 - Resume
### James Iden Busia

### Input
The input is simple HTML in the form of JSX in Resume.js supported by CSS in Resume.css. These are loaded by the App.js and rendered as a React component.

### Process
App.js links Resume.js and Resume.css and renders the Resume component from Resume.js in the primary App div. All of the HTML is rendered here, and the CSS is imported from Resume.js.

### Output
The HTML in the Resume component is rendered in the browser window supported by the CSS imported from Resume.css.
